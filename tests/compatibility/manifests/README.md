# golden compatibility fixtures — **ห้ามแก้**

manifest ในโฟลเดอร์นี้คือ **ตัวแทนของ manifest ที่มีคนเขียนไปแล้วในโลกจริง**
หน้าที่เดียวของมันคือยืนอยู่เฉย ๆ แล้วพิสูจน์ว่า Builder รุ่นใหม่ยังรับมันได้

> ถ้าแก้ไฟล์ในนี้ แปลว่าเปลี่ยนคำถามที่ test ถาม — ซึ่งทำให้ test ตอบว่า "ผ่าน"
> โดยไม่ได้พิสูจน์อะไรเลย checksum ของแต่ละไฟล์ถูกล็อกไว้ใน `baseline.json` ด้วย
> เหตุผลนี้

ต่างจาก [`../conformance/vectors/`](../conformance/vectors/) ตรงที่ vector **ปรับได้**
เมื่อเราเข้าใจเรื่องที่มันทดสอบดีขึ้น ส่วนไฟล์ในนี้ **ไม่ปรับ** — ของเก่าที่ยังต้องใช้ได้
คือทั้งหมดของความหมายมัน

เพิ่มไฟล์ใหม่ได้ ลบหรือแก้ไม่ได้ (เว้นแต่ bump contract version พร้อมเหตุผล)
